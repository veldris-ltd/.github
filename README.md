## How GitHub uses this repository

- `profile/README.md` is rendered on the organisation's public overview page.
- Community health files placed at the root of this repository, or in a `.github/` directory within it (for example `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md`, issue and pull request templates), act as defaults for any public repository in the organisation that does not define its own. A repository's own file always takes precedence.

## Editing rules

1. This repository is public. Do not add internal hostnames, infrastructure details, credentials, private repository names or unreleased product information.
2. State only facts that are verifiable from a public repository or a Veldris publication. Do not describe planned work as live. Use hedged wording ("intended", "targeted", "expected") for anything not yet released.
3. Use British English and the Veldris house style. Do not use em dashes, en dashes or double hyphens in prose.
4. Company details must match exactly: Veldris Ltd, registered in England and Wales, company number 17366869, registered office Two Snowhill, Birmingham, B4 6WR, ICO registration ZC222667.
5. When a repository is made public, renamed or archived, update `profile/README.md` in the same change. Midgard figures (acceptance gate results, product status) must match the `midgard-app` README and claims ledger at the time of the change.
6. Badges use the Veldris palette: label `#12161F`, message `#8C6526` (deep brass, chosen over `#B8873B` for WCAG 2.1 AA contrast with white text) or `#CA1D25` for Midgard.
7. Commits must be signed. Changes reach `main` through a reviewed pull request.
